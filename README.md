# Lynx Customer Address

`oocscommerce/module-lynx-customer-address`

Address form fields of the Lynx storefront, managed in the admin.

## Features

- Stores > Attributes > Customer Address Fields: drag to order, column width, required, length and input validation
- One set of rules for the checkout, the address book and registration
- Saved to Magento's own attribute settings, so the server validates with the same rules

## Installation

Part of [Lynx](https://docs.oocscommerce.com/lynx/), installed with the metapackage:

```bash
composer require oocscommerce/magento2-lynx-community
```

See [Installation](https://docs.oocscommerce.com/lynx/developer/installation) for the full setup.
